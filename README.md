# Marta Cruz Ortiz — Portfolio (AI Creative & DJ Candadismo)

Web estática (HTML + CSS, sin dependencias). Bilingüe EN/ES con botón en la barra superior.

## Publicar en GitHub Pages
1. Crea un repo en GitHub. Si lo llamas `TU-USUARIO.github.io`, la web quedará en `https://TU-USUARIO.github.io`.
2. Sube todo el contenido de esta carpeta (index.html, ia.html, dj.html, styles.css, main.js, assets/) a la raíz del repo
   (en GitHub: **Add file → Upload files** y arrastra los archivos).
3. Ve a **Settings → Pages → Build and deployment → Source: Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
4. En 1–2 minutos estará online.

## Editar
- Textos: `index.html` (portada), `ia.html` (trabajos IA) y `dj.html` (DJ) (cada texto tiene versión `class="en"` y `class="es"`).
- Colores y tipografías: arriba del todo en `styles.css` (`--pink`, etc.).
- Imágenes: `assets/img/` — sustituye un archivo por otro con el mismo nombre.
